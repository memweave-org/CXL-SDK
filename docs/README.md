# Repository technical guides

This directory contains technical notes for the source tree. It is independent
of the separately hosted documentation site.

- [Configuration](configuration.md): file-backed and device-backed shared-memory settings.
- [Validation](validation.md): CI checks, component tests, and hardware limits.
- [Architecture diagram](arch.html): editable HTML version of the layered architecture illustration.
- [Architecture README preview](arch.svg): editable SVG view that follows the original PNG layout.

Component-specific instructions remain beside their code, for example
[`STL/README.md`](../STL/README.md) and
[`tests/YCSB-C/README.md`](../tests/YCSB-C/README.md).
